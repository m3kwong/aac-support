Caregiver PIN recovery

Use PIN recovery to choose a new caregiver PIN in AAC. Your words, boards, and settings will be kept.

Recovery code

Recovery Code: 748296

Reset your PIN

  1. In the app, open the Caregiver Access PIN prompt and tap Forgot PIN?.
  2. On PIN Recovery, enter your recovery code in Recovery Code, then tap Continue.
  3. On Set PIN, enter a new PIN of 4–8 digits in New PIN and enter it again in Confirm PIN.
  4. Tap Save PIN. Keep your new PIN somewhere safe.

If you opened this page from the app, return to the app to enter the code. If the recovery screen has closed, tap Forgot PIN? again.

If recovery fails

Enter the code exactly, without spaces. If saving fails, your previous PIN stays active; try saving again.

You do not need to purchase Unlock to recover an existing PIN. Recovery does not unlock paid features.

The caregiver PIN helps prevent accidental editing. It is not device-owner authentication.
